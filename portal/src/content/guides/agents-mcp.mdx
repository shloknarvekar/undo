---
title: Connect an AI agent
description: Let any MCP-capable agent shop under a shopper's mandate.
---

Outside agents connect over MCP (Streamable HTTP) instead of calling the HTTP API directly. The agent never signs anything: it asks for a mandate, the shopper signs it on their own device, and from then on the agent can only buy what that mandate allows.

```text
https://undo-1c56.onrender.com/api/mcp
```

## Claude Code

```bash
claude mcp add --transport http undo https://undo-1c56.onrender.com/api/mcp
```

On claude.ai or Claude Desktop, add a custom connector with the same URL.

## Tools

| Tool | What it does |
|---|---|
| `undo_request_mandate` | Ask the shopper for a mandate. Returns a link they open to review and sign it. |
| `undo_get_mandate` | Check whether the mandate is signed, and read its limits. |
| `undo_search_products` | Search the live catalog inside the mandate's limits. |
| `undo_check_cart` | Check a cart against the mandate before proposing it. |
| `undo_propose_cart` | Buy. Opens a PayPal checkout that only holds the money. |
| `undo_get_order` | Read the order, its undo window and its record. |

## Registered and unregistered agents

Agents without a key are recorded as **unregistered**. An operator whose key Undo has registered connects with `Authorization: Bearer <key>` and becomes **registered**. A mandate signed for a registered agent can only be used with that key.

The store can refuse low-trust agents or give their purchases a longer undo window; see [`GET /api/merchant/agents`](/api/undo/merchant/listMerchantAgents) and [`PUT /api/merchant/rules`](/api/undo/merchant/updateMerchantRules). When an agent breaks a mandate, its operator is the one who pays the merchant back.
