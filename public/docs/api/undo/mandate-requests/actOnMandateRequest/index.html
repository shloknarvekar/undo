Mandate requests

Answer, prepare or sign a mandate request

POST
/api/mandate-requests/{requestId}
  • answer: answers the agent's open questions; the draft is re-read from the new text.
  • prepare: the exact mandate this device's key must sign.
  • sign: stores the signed mandate; it must match the request byte for byte (same words, limits and agent).

Path Parameters

requestId*string

Mandate request id.

Formatuuid

Request Body

application/json

The shopper's answer, a request to prepare the mandate, or the signed mandate.

One of answer, prepare or sign, chosen by action.

Answer the agent's open questions.

action*"answer"

Always answer.

Value in

  • "answer"
answers*

Each open question (exactly as asked) mapped to the shopper's answer.
