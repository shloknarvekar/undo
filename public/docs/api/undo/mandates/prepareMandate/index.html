Mandates

Build the exact mandate to sign

POST
/api/mandates/prepare

Returns the mandate the shopper's device must sign and the exact signingMessage (undo-intent-mandate-v1:<sha256 of the canonical mandate JSON>). Stateless; nothing is stored.

Request Body

application/json

The draft, the shopper's words and the device key that will sign.

What's needed to build the exact mandate a device will sign.

request*string

The shopper's request in their own words, kept verbatim inside the mandate.

Length3 <= length <= 1000
draft*

The shopper's limits in structured form.

shopperKey*string

Base64 Ed25519 public key.

Length40 <= length <= 60
payWith?"saved_wallet"

How the agent may pay.

Value in

  • "saved_wallet"
