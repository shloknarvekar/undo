Shop inside a mandate

POST
/api/mandates/{mandateId}/shop

Undo's agent searches, checks the cart against the signed limits, and opens a PayPal checkout in AUTHORIZE mode. Without a saved wallet the shopper approves at approveUrl; with one (and only if the mandate allows it) the money is held straight away. One live purchase per mandate. Rate limited per visitor.

Mandate id.
