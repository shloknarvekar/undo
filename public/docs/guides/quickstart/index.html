Quickstart

Read a real finished order in one call.

This order is a finished case from the live sandbox: a careless agent bought shoes in size 10.5 when the shopper signed for 10. The money had already been captured when the shopper pressed Undo. The fault check found the agent at fault, so the shopper got a full refund and the agent's operator paid the merchant back through PayPal Payouts.

What comes back

FieldWhat it tells you
order.statusWhere the purchase stands. AUTHORIZED means the money is only held and Undo is a free void.
order.paypalThe PayPal order, authorization and capture ids behind it.
order.resolutionThe verdict, the evidence, what happened to the money, and any payout from the agent's operator.
undoWindowHow long the window is, why, and whether it's still open.
chain.eventsEvery step, oldest first. Each one carries a proof saying how it was decided and which PayPal call backs it.
